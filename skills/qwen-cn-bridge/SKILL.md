# 千问助手

需要查证中国大陆近期资讯、12306、微信、支付宝、淘宝、美团、小红书的实操规则，或理解中文网梗、亚文化和本土商业动态时，直接调用插件 MCP 工具 `ask_qwen`。禁止运行终端命令调用千问。用精简的中文问题说明时间范围、地区和需要的来源链接。默认开启新对话。仅在用户明确需要延续同一千问对话时设置 `new_chat: false`。

仅使用免费的 Qwen-快速。绝对禁止向千问发送政治敏感、违规违法内容或用户隐私、凭证和内部资料。禁止绕过登录、验证码或风控。遇到 `NOT_LOGGED_IN` 或 `CAPTCHA_OR_BLOCKED` 时，调用 `open_qwen_panel`，或请用户在左侧栏打开「千问助手」并点击「登录 / 切换千问账号」完成验证。遇到 `MODE_CHECK_FAILED` 时，请用户在登录窗口手动确认「快速」。超时后先确认是否已经提交，避免重复发送。

把结果作为待核实的本土资料。独立检查关键事实、适用地区、日期和来源，再用符合当前任务的语言组织答案。
